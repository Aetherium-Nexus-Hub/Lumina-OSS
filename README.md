# Lumina-OSS: Shader Pilot

**Description:** A retro-scifi GLSL exploration ship. Travel through procedurally generated 3D fractal worlds with heavy analog aesthetics, scanlines, and vangelis-style synth soundtracks.

## Overview

Lumina-OSS presents "Shader Pilot," an immersive experience that transports users into a retro-futuristic universe. This project leverages GLSL shaders to render stunning, procedurally generated 3D fractal environments, complete with nostalgic analog visual effects like scanlines and a captivating Vangelis-inspired synth soundtrack. It's an exploration into the artistic and technical possibilities of real-time graphics.

## Features

*   **Procedural 3D Fractal Worlds:** Explore infinitely generated and unique fractal landscapes.
*   **Retro-SciFi Aesthetics:** Enjoy a visually rich experience with analog effects and scanlines.
*   **Dynamic GLSL Shaders:** Witness the power of real-time graphics rendering.
*   **Vangelis-Style Soundtrack:** Immerse yourself with an evocative synth-wave audio experience.

## Getting Started

### Prerequisites

*   Node.js

### Local Development

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Configure API Key:** Set your `GEMINI_API_KEY` in the `.env.local` file (if applicable for any integrated AI features).
3.  **Run the application:**
    ```bash
    npm run dev
    ```
